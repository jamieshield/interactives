Sequence diagram editor

This editor allows the modelling of lag, reordering, receipt and delivery of messages between nodes. This prototype helped students to visualise consistency models such as linearisability, and sequential and causal consistency.

The notation is inspired by PlantUML. Unfortunately PlantUML does not provide sufficient support for overlapping messages. The code is genAI.

Message are denote by participant -> participant. Delays are denoted by parenthesised numbers before or after the arrow. The ampersand (&) starts the next message relative to the previous message.

The above is a div that is followed by a script. The script attaches the editor to the current element, i.e. div. There is a options dictionary which configures the button. A simulated button was needed to use the editor inside Moodle quizzes which stripped true buttons.

As a step towards understanding sequential and causal consistency models, the receival of messages was distinguished from the delivery of messages. Reflexive, dotted red lines were used to denote message delivery.
